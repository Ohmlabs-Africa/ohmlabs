# OHM Labs

The OHM Labs website presents the company's digital transformation services and gives clients a place to connect with the team and follow project work.

## Features

- Responsive pages for company information, services, projects, and solutions
- Contact, project proposal, and font submission forms
- Appointment booking through the calendar integration
- Separate admin and client sign-in
- Client registration with admin approval
- Protected client project workspace for shared tasks, tickets, and project chat
- Admin dashboard for account approvals, submissions, statistics, and project management
